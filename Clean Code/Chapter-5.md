                                                                Formatting








Code formatting is very important
Source file should be like a newspaper article,
    - name should be simple,but explanatory. THe name shoud be enough to tell if its the right module or not
    - Topmost part of file should provide high level concepts also algorithms
    - Detail should increase as we go downward

Use blank lines to cue a separate concept
Concepts closely related should be kept vertically closed to each other
VARIABLE DECLARATION: Variables should be declared as close to their usage as possible
    Instance variables should be declared at the top of the class

If one function calls another, they should be vertically close, and the caller should be above the callee,this gives a natural flow
